#  VK Analytics & AI Agent

Информационная система для автоматизированного сбора, семантической обработки и интерактивного анализа неструктурированных данных из социальной сети ВКонтакте (VK) с использованием больших языковых моделей (LLM).

---

## Описание проекта

### Что делает система?
Это комплексный инструмент для медиа-аналитики, который берет на себя рутинные задачи по работе с социальными сетями:
1. **Собирает данные:** Автоматически парсит посты и тысячи комментариев по заданным ключевым словам через VK API .
2. **Анализирует тональность:** Прогоняет собранные тексты через ML-модель (трансформер), присваивая каждому комментарию метку: *Позитивный / Негативный / Нейтральный* с оценкой уверенности.
3. **Отвечает на вопросы (ИИ-Агент):** Позволяет общаться с базой данных на естественном языке. Агент сам переводит ваш запрос (например, *"Покажи основные жалобы пользователей за последнюю неделю"*) в SQL-фильтры, делает выборку из БД и генерирует подробный текстовый отчет на основе найденного контекста.

### Для кого этот проект?
* **Маркетологи и бренд-менеджеры:** Для мониторинга репутации, отслеживания реакции на рекламные кампании и релизы продуктов.
* **Продакт-менеджеры:** Для агрегации пользовательских жалоб и предложений напрямую из комментариев.
* **Медиа-аналитики и социологи:** Для изучения общественных настроений и выявления скрытых трендов.


### 🛠 Технологический стек
* **Backend:** Python 3.10+, FastAPI, SQLAlchemy (Async), Pydantic.
* **Database:** PostgreSQL .
* **Machine Learning:** PyTorch, Hugging Face `Transformers` (Sentiment Analysis & LLM).
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API).
* **Infrastructure:** Docker 



# Развертывание системы.
Для запуска системы используйте Docker
```
git clone <repo-url>
cd vk-analytics-ai-agent
```

Создайте или отредактируйте файл env по шаблону
```env
# ==========================================
# VK API (Для сбора данных)
# ==========================================
# Сервисный ключ или токен доступа для VK API
VK_ACCESS_TOKEN=your_vk_service_token_here
# Версия API (рекомендуется 5.131 или выше)
VK_API_VERSION=5.131

# ==========================================
# PostgreSQL (База данных)
# ==========================================
POSTGRES_USER=admin
POSTGRES_PASSWORD=your_secure_password
POSTGRES_DB=vk_analytics
# Строка подключения для FastAPI (asyncpg)
DATABASE_URL=postgresql+asyncpg://admin:your_secure_password@db:5432/vk_analytics

# ==========================================
# Machine Learning & LLM
# ==========================================
# ID модели в HuggingFace для диалогового агента 
MODEL_NAME=
# ID модели для классификации тональности
SENTIMENT_MODEL=
# Устройство для вычислений: 'cuda' (если есть NVIDIA GPU) или 'cpu'
DEVICE=cuda
# Директория внутри контейнера для кэширования весов моделей
CACHE_DIR=/app/cache/models

# ==========================================
# Параметры генерации LLM
# ==========================================
# Максимальная длина ответа модели в токенах
MAX_NEW_TOKENS=2048
```
После чего запустите сборку контейнера и перейдите в браузере по адресу http://localhost:8550/
```
docker-compose up -d --build
```
